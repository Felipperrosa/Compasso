# Resumo da Sprint 4

**Python:** 
Aprendi programação funcional em Python explorando como funções podem ser tratadas como objetos de primeira classe. Descobri que é possível usá-las para transformar coleções de dados com ferramentas como map, filter e reduce. Também entendi a importância de evitar estados mutáveis e escrever funções puras para manter o código previsível. Foi interessante ver como a composição de funções facilita a criação de soluções mais claras e reutilizáveis. Essa abordagem me ajudou a pensar de forma mais declarativa ao resolver problemas

**Docker:** 
Neste curso, aprendi as funcionalidades do Docker do básico ao avançado. Aprendi fluxos com containers, criação e atualização de imagens, disponibilização no Docker Hub, utilização de Volumes e Bind Mount, criação de Networks, conexões externas e entre containers, além do uso do Docker Compose para gerenciar múltiplos containers.

**AWS Partners:** 
Neste curso, aprendi sobre a presença global da AWS e como ela impacta as implantações dos clientes. Explorei os principais serviços da AWS, entendendo como aplicá-los em arquiteturas e casos de uso comuns. Além disso, compreendi os resultados do AWS Cloud Adoption Framework (AWS CAF) na jornada do cliente, identifiquei estratégias de migração adequadas para diferentes cargas de trabalho e aprendi a usar o Well-Architected Framework para revisar e aprimorar arquiteturas de sistemas
