# Resumo da Sprint 1

**Git Hub:**  Já possuía um conhecimento básico de Git, o que me permitiu aperfeiçoar ainda mais minhas habilidades, especialmente em relação às boas práticas. O curso foi excelente, pois abordou desde os comandos mais simples, como git commit, até os mais avançados, como o uso de git branch para gerenciar e alternar entre diferentes versões do código. A forma como o curso foi estruturado foi muito eficaz, proporcionando uma compreensão profunda do Git e suas funcionalidades. Me sinto mais confiante para aplicar as técnicas aprendidas em projetos reais, otimizando o fluxo de trabalho e garantindo um controle de versão eficiente



**Linux:**: Aprendi desde os comandos básicos do Linux até os mais avançados, o que me proporcionou uma compreensão sólida do sistema operacional. Aprofundei meus conhecimentos em tarefas essenciais, como navegação no terminal, manipulação de arquivos e permissões, até comandos mais complexos para automação de processos e administração do sistema. Esse aprendizado me deixou mais preparado para gerenciar servidores e otimizar o ambiente de desenvolvimento de forma eficiente
