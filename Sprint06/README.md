# Resumo da Sprint 6

**AWS Skill Builder - Fundamentals of Analytics on AWS – Part 1 (Portuguese):** 
Este curso me apresentou às tendências atuais no mercado de analytics, sendo a primeira etapa de uma jornada em duas partes. Aprendi os conceitos básicos de analytics, incluindo os diferentes tipos, os 5 Vs do big data (volume, variedade, velocidade, veracidade e valor) e os desafios de processar grandes volumes de dados. Além disso, explorei como esses 5 Vs se relacionam com os serviços de analytics da AWS e como a AWS oferece uma solução abrangente para essas necessidades. Com esse conhecimento, estou preparado para avançar para a segunda parte da série, aprofundando minha compreensão em analytics na AWS.

**AWS Skill Builder -  Fundamentals of Analytics on AWS – Part 2 (Portuguese) :**
Eu aprendi a expandir os conceitos de analytics apresentados na Parte 1, explorando data lakes, data warehouses e arquiteturas de dados modernas na AWS. Entendi como usar serviços da AWS para criar essas soluções e suas aplicações no mercado. Também conheci casos de uso comuns dessas arquiteturas e examinei uma arquitetura de referência, consolidando meu conhecimento sobre como a AWS suporta a construção de sistemas de dados eficientes e escaláveis.

**AWS Skill Builder - Serverless Analytics (Portuguese):**
Eu aprendi a lidar com dados de diversas formas e origens, conectando e processando essas informações para tomar decisões mais embasadas por dados. Com as orientações de Glenn Gillen, explorei como usar ferramentas como AWS IoT Analytics, Amazon Cognito, AWS Lambda e Amazon SageMaker. Aprendi a agregar, processar, armazenar e disponibilizar dados de maneiras inovadoras e eficazes, aproveitando o potencial dessas tecnologias para criar soluções poderosas e orientadas por dados.

**AWS Skill Builder - Introduction to Amazon Athena (Portuguese):**
Eu aprendi sobre o Amazon Athena, incluindo uma visão geral do seu ambiente operacional e as etapas básicas para sua implementação. No curso, explorei como usar o Console de Gerenciamento da AWS para criar um banco de dados e executar consultas SQL para validação, compreendendo melhor como o Athena facilita a análise de dados diretamente no S3 de maneira eficiente e sem necessidade de infraestrutura complexa.

**AWS Skill Builder - AWS Glue Getting Started (English):**
Eu aprendi sobre o AWS Glue, um serviço serverless de integração de dados usado para descobrir, preparar e combinar dados para análises, aprendizado de máquina e desenvolvimento de aplicações. O curso abordou os benefícios, casos de uso comuns e conceitos técnicos do AWS Glue, incluindo o AWS Glue Studio e o AWS Glue DataBrew. Aprendi que o DataBrew é uma ferramenta visual de preparação de dados que permite a analistas e cientistas de dados limpar e normalizar dados para análises e aprendizado de máquina. Além disso, tive a oportunidade de explorar o serviço por meio de uma demonstração prática no Console de Gerenciamento da AWS.

**AWS Skill Builder - Amazon EMR Getting Started (English):**
Eu aprendi sobre o Amazon EMR, a solução líder em big data na nuvem para processamento de dados em escala de petabytes, análises interativas e aprendizado de máquina, utilizando frameworks de código aberto como Apache Spark, Apache Hive e Presto. O curso destacou o Amazon EMR Serverless, uma opção eficiente e econômica que permite a engenheiros e analistas de dados executar aplicações sem a necessidade de gerenciar, otimizar ou operar clusters. Também explorei os benefícios, casos de uso e conceitos técnicos do Amazon EMR. Tive a oportunidade de experimentar o Amazon EMR Serverless e o Amazon EMR Cluster por meio de tutoriais no Console de Gerenciamento da AWS.

**AWS Skill Builder - Getting Started with Amazon Redshift (Portuguese):**
Eu aprendi sobre o Amazon Redshift, um serviço de data warehouse na nuvem integrado com data lakes no Amazon S3 e com serviços de banco de dados relacional como Amazon RDS e Amazon Aurora. O curso destacou os benefícios, casos de uso comuns e conceitos técnicos do Redshift. Também explorei como o Redshift permite a criação e utilização de modelos de machine learning (ML) diretamente com comandos SQL familiares, simplificando o uso de ML. Além disso, tive a oportunidade de experimentar o serviço por meio de uma demonstração prática no Console de Gerenciamento da AWS.

**AWS Skill Builder - Best Practices for Data Warehousing with Amazon Redshift (Portuguese):**
Eu aprendi sobre os conceitos de implementação de um data warehouse utilizando o Amazon Redshift. O curso abordou o design básico de tabelas, armazenamento e ingestão de dados, além de técnicas de gerenciamento de workload. Também explorei como o dimensionamento de nós e clusters afeta o desempenho e a escalabilidade do data warehouse.

**AWS Skill Builder - Amazon QuickSight - Getting Started (English):**
Eu aprendi sobre o Amazon QuickSight, um serviço de inteligência empresarial (BI) em escala de nuvem que permite criar e publicar dashboards interativos acessíveis por navegadores ou dispositivos móveis. O curso destacou os benefícios e conceitos técnicos do QuickSight, incluindo sua arquitetura e recursos integrados. Entendi como o serviço combina dados de várias fontes e oferece ferramentas de gerenciamento de usuários, permitindo escalabilidade de alguns usuários para milhões. Também tive a oportunidade de experimentar recursos essenciais por meio de demonstrações práticas.

Query que lista os 3 nomes mais usados em cada década desde o 1950 até hoje.

```SQL
WITH decada AS ( 
  SELECT
    nome,
    ano,
    total,
    FLOOR(ano / 10) * 10 AS decada
  FROM meubanco.nomes
  WHERE ano >= 1950
),
ranqueado AS (
  SELECT
    decada,
    nome,
    SUM(total) AS total_decada,
    ROW_NUMBER() OVER (
      PARTITION BY decada 
      ORDER BY SUM(total) DESC
    ) AS posicao_decada
  FROM decada
  GROUP BY decada, nome
)
SELECT
  nome,
  decada,
  total_decada
FROM ranqueado
WHERE posicao_decada <= 3
ORDER BY decada, posicao_decada;

```
